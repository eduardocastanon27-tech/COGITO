```
cp ~/.config/app/notes.md   /tmp/notes.config.bak
cp ~/project/notes.md        /tmp/notes.project.bak
```

**2. Look at what each has that the other lacks — both directions.**
```
diff ~/.config/app/notes.md ~/project/notes.md
```
Lines marked `<` live only in the config copy; `>` only in the project copy. This is the whole point: it shows you the edits each file would lose in a blind copy.

**3. Build the merged superset.** There's no shared starting point (they diverged with no common ancestor), so no tool can auto-merge these cleanly — it's a judgment call per difference. **4. Copy the merged file to the other path** — now it's safe, because this file is the superset, not one original clobbering the other.


**5. Verify they're actually identical.**
```
cmp ~/.config/app/notes.md ~/project/notes.md && echo "identical"
```
`cmp` exits silently and prints `identical` only if every byte matches.
